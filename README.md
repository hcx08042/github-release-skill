# GitHub Release Skill

GitHub 仓库发布流程自动化技能。帮助你一键完成从本地项目到 GitHub Release 的完整发布流程。

## 功能

- ✅ 检查并安装 Git
- ✅ 检查并安装 GitHub CLI (gh)
- ✅ GitHub 登录授权
- ✅ 初始化 Git 仓库
- ✅ 创建 GitHub 仓库并推送代码
- ✅ 创建版本 Tag
- ✅ 发布 GitHub Release

## 安装

将本目录放置于 Claude Code 可以访问的位置即可。

## 使用方法

在 Claude Code 会话中：

```
/github-release-skill
```

或直接在请求中说明：
```
请帮我把这个项目发布到 GitHub
```

## 工作流程

1. 检查 Git 和 GitHub CLI 安装状态
2. 检查 GitHub 登录状态
3. 创建 GitHub 仓库
4. 推送代码到远程
5. 打 Tag 并发布 Release
